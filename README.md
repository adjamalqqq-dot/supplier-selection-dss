# Supplier Selection Decision Support System

BIT2014 individual final project. The example is fictional, and all prices and scores are synthetic. No real personal data are included in the dataset.

## Run the model
Open Supplier_Selection_DSS.xlsx in Excel or a compatible spreadsheet application with automatic calculation enabled. On the Supplier DSS sheet, review the four supplier records and weights. Base weights are 30%, 30%, 25% and 15%. Supplier B ranks first with 81.50 points. Changing weights to 60%, 15%, 15% and 10% makes supplier A first with 88.25 points. Restore the original weights afterwards. Invalid or missing inputs suppress totals and ranks.

## Contents
- Supplier_Selection_DSS.xlsx: self-contained spreadsheet, dataset and formulas.
- synthetic_supplier_data.csv: the four fictional records.
- screenshots/: rendered workbook and test-case views.
- model.mjs: authoring source, retained for transparency. Regeneration needs the @oai/artifact-tool runtime and its dependencies; the workbook itself does not.
